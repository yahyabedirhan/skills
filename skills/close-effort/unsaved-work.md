# Unsaved work

## In a worktree

Removing a worktree deletes its ignored and untracked files without asking. `git status --ignored` lists both; plain `git status` hides the ignored ones. Copy out what's worth keeping, where `/orchestrating`'s `folder-standard.md` puts it, and copy editor settings like `.vscode/` to the main checkout.
