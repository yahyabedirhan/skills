# Profile: Cursor Dark

The Cursor Dark editor palette with editorial serif titles. The default for any diagram.

## Diagram types

Any upstream type.

## Diagram style

Minimal dark.

## Look

Upstream defaults. Callouts are not italic.

## Typography

| Role | Family | Weight |
|---|---|---|
| `title` | Fraunces (default), Lora or Literata | 600, normal tracking |
| `node-name` | Geist | 600 |
| `sublabel` | Geist Mono | 400 |
| `callout` | Geist, not italic | 400 |

Use Geist Mono for all technical text.
