# Agent instructions

## Agent skills

### Issue tracker

Issues live in this repo's GitHub issues (`yahyabedirhan/skills`), through the `gh` CLI. There are no triage labels: label a new issue `enhancement` or `bug`, whichever fits.

### Writing skills

Before writing or changing a skill, read `docs/decisions/skill-writing.md`: the shape, the language and what a skill leaves out and keeps.
