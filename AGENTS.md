# Agent instructions

## Agent skills

### Issue tracker

Issues live in this repo's GitHub issues (`yahyabedirhan/skills`), through the `gh` CLI. There are no triage labels: label a new issue `enhancement` or `bug`, whichever fits.

### Domain docs

Single-context: one `GLOSSARY.md` at the root when terms get settled, and the decision records in `docs/decisions/`. See `docs/agents/domain.md`.

### Writing skills

Before writing or changing a skill, read `docs/decisions/skill-writing.md`: the shape, the language and what a skill leaves out and keeps.

### Writing research

Before writing or changing research documentation (`docs/research/`, Markdown or an HTML guide), read `docs/decisions/research-writing.md`: a light version of ASD-STE100 for every sentence, and one folder per topic.
